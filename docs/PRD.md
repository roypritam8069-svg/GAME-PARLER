# Game Parlour Website — Product Requirements Document

## 1. Project Purpose
A professional single-location physical gaming parlour website.

Customers can:
- Discover the parlour
- View PlayStation/consoles and games
- View pricing
- Check physical station availability
- Select date, time and duration
- Book a physical gaming session
- Pay online or choose counter payment
- Receive Booking ID and QR
- Receive WhatsApp confirmation
- Find the physical parlour location

IMPORTANT:
This is NOT an online gaming platform.
Customers must physically visit the parlour to play.

## 2. Project Scope

- Single physical Game Parlour
- Responsive website
- Website + WhatsApp-assisted + Counter/Admin booking
- One Owner/Admin
- No membership in MVP

## 4. Customer Information

Required:
- Name
- Phone/WhatsApp

Optional:
- Email

Only minimum necessary information should be collected.

## 5. Payment

Support:
- Online payment gateway
- Cash/Counter payment

Never store raw card data.

Store only payment-provider reference/token and status where required.

## 6. Booking Confirmation

After confirmation:
- Unique Booking ID
- Booking details
- Date
- Time
- Duration
- Station
- Game
- Amount
- Payment status
- QR code
- WhatsApp notification

WhatsApp notification requires explicit opt-in.

Marketing consent must be separate.

## 7. Cancellation & Refund

## 14. Acceptance Criteria

- Games viewable
- Pricing viewable
- Physical location visible
- Availability check works
- Date/time/duration selection works
- Booking works
- Server validates availability
- Server calculates price
- Double booking prevented
- Booking ID generated
- QR generated
- Payment verified server-side
- Counter payment supported
- WhatsApp opt-in respected
- Cancellation/refund policy enforced
- Owner can manage parlour
- English/Bengali work
- Mobile booking works
- No online gaming functionality
